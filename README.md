# Interactive companion to "Patience and the Harshest Punishment in Repeated Cournot Oligopoly"

Live page: https://rabbanimaysam.github.io/penal-codes-interactive/

Interactive versions of Figures 1 and 2 of the paper: the jump in the worst punishment payoff along the discount factor (Figure 1), the jump size for truncated linear demand (Figure 2, panels a and b), and the classification map for constant-curvature demand (Figure 2, panel c). The page is a single HTML file; all computation runs in the browser and reproduces the paper's R scripts.

Maysam Rabbani, Department of Economics, Montclair State University.
